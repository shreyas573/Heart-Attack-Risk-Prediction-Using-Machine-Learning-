# Heart Attack Prediction Using Machine Learning

## 📌 Project Overview

Heart Attack Prediction Using Machine Learning is a healthcare-focused machine learning project that predicts whether a person is at risk of heart disease based on clinical and health-related attributes.

The project uses machine learning algorithms to analyze patient data and identify important factors associated with heart disease. Explainable AI (XAI) using SHAP is also incorporated to make the model predictions easier to understand.

---

## 🎯 Objectives

- Predict the risk of heart disease using patient health data.
- Perform data preprocessing and exploratory data analysis.
- Compare multiple machine learning algorithms.
- Select an appropriate model based on evaluation metrics.
- Identify important risk factors affecting predictions.
- Use SHAP for explainable AI and model interpretation.
- Provide an understandable prediction result for users.

---

## 🗂️ Dataset

The project uses the **UCI Cleveland Heart Disease Dataset**.

The dataset contains clinical attributes related to heart disease.

### Major Features

| Feature | Description |
|---|---|
| age | Age of the patient |
| sex | Gender |
| cp | Chest pain type |
| trtbps | Resting blood pressure |
| chol | Cholesterol level |
| fbs | Fasting blood sugar |
| restecg | Resting ECG results |
| thalachh | Maximum heart rate achieved |
| exng | Exercise-induced angina |
| oldpeak | ST depression |
| slp | Slope of peak exercise ST segment |
| caa | Number of major vessels |
| thall | Thalassemia |
| output | Heart disease target |
